    作品六：個人每日管理工具｜技術設計¶

    本文件先記錄已確定的技術方向。React 元件切分、狀態管理與套件選擇，實作時再決定。

    1. 技術組合¶

    項目 技術
    前端 React + TypeScript
    開發／建置 Vite
    CSS Tailwind CSS
    架構 SPA
    本地儲存 localStorage
    部署 GitHub Pages
    • 不建立會員、後台、後端 API 或雲端資料庫。
    • 優先完成網頁版 MVP。

    2. 全站共通技術需求¶

    • RWD：桌面、平板、手機。
    • Dark Mode：Light／Dark／System。
    • i18n：繁體中文／English（日韓文視需求擴充）。
    • Components：適度共用元件，遵守 DRY，避免過度抽象。
    • a11y：語意化 HTML、鍵盤操作、焦點狀態與對比。
    • UI 狀態：依實際需求處理空資料、錯誤提示等。
    • 表單驗證：必要欄位與格式檢查，避免不必要的複雜驗證。

    3. 本地資料與備份¶

    • 所有個人紀錄存在使用者瀏覽器的 localStorage。
    • 集中管理 localStorage 的讀取、更新與寫入邏輯。
    • 編輯後立即更新 UI 並持久化。
    • 日曆與工作區讀取同一份來源資料，不另複製紀錄。
    • 不主動上傳個人紀錄；網站託管服務仍可能保有基本連線紀錄。
    • localStorage 不是桌面檔案；清除網站資料可能造成遺失。
    • JSON 匯出保存完整資料及設定；Markdown 匯出供人閱讀。
    • 匯出使用瀏覽器下載機制，不能保證自動存到桌面。
    • 第一版不做 JSON 匯入還原。

    4. 日期與日更¶

    • 預設工作日分界：本地時間 04:00，可由設定修改。
    • 例：11/22 03:50 屬於 11/21；11/22 04:00 屬於 11/22。
    • 保留事件實際時間，另計算其所屬工作日期。
    • 完成事件立即儲存並呈現在對應工作日日曆。
    • 「儲存事件」與「跨日整理」分開處理。
    • 開啟網站、恢復分頁與持續使用跨過分界時，檢查是否需要日更。
    • 日更建立新每日打卡清單，隱藏前一工作日已完成任務。
    • 不清空待辦／進行中任務，也不刪除歷史資料。
    • 多天未開啟不需要逐日建立沒有實際操作的活動紀錄。

    5. 資料模型方向（暫不定義欄位 Schema）¶

    • 每日模板：文字項目清單。
    • 每日打卡：工作日期、項目文字、勾選狀態、Memo。
    • 任務看板：任務文字、所屬欄位、排序、完成時間、封存狀態。
    • 自由便籤：文字、尺寸（小／中／大）、排列順序。
    • 番茄紀錄：專注分類、實際認列時長、番茄數、完成時間。
    • 手動活動：日期、時間、時長（可空）、備註。
    • 設定：外觀、語言、每日分界、提示音、上次頁面／工作區模式。

    每日打卡的文字與 checked 狀態應屬於同一筆項目；不需要連結任務看板，也不需要跨日共用同一個習慣項目 ID。

    6. 番茄鐘計時實作原則¶

    • 使用時間戳記計算剩餘時間與經過時間，不只依賴 setInterval 每秒遞減。
    • 暫停、繼續時須正確扣除暫停時間。
    • 倒數歸零時建立一次紀錄，避免重新渲染或分頁恢復時重複新增。
    • 倒數完成後進入正計時；超時不自動增加番茄。
    • 按 × 結束正計時，不重複建立紀錄。
    • 若使用者確實持續專注，可手動修改該筆紀錄。
    • 網頁在手機背景或鎖定時可能限制計時回呼、音效及通知。
    • 時間戳記可校正畫面時間，但不保證背景準時播放聲音。

    7. 拖曳與版面¶

    • 任務看板支援三欄間拖曳及欄內排序。
    • 便籤支援拖曳排序，小／中／大三種尺寸。
    • 便籤採 CSS Grid 自動排列，依螢幕寬度調整欄數。
    • 可研究 dnd-kit；是否使用套件等到實作時再決定。
    • 不做自由座標、重疊視窗與磁吸演算法。

    8. 開發與部署¶

    • 優先確保儲存、日更、拖曳、計時邏輯正確。
    • 各功能先完成基本操作，再整合共用資料與日曆。
    • 避免為單一用途過度抽象。
    • 完成後部署 GitHub Pages。
    • 搜尋、排序、分頁等額外功能依需求決定；即時同步與進階通知暫不考慮。

    9. 未來跨平台方向（非 MVP）¶

    1. React 網頁版：GitHub Pages。
    2. PWA：研究 iOS／Android 安裝到主畫面及基本離線能力。
    3. Capacitor：沿用大部分 React 程式碼，封裝 iOS／Android App。

    4. Tauri：研究 Windows 桌面可攜版。

    5. 原生手機通知、鎖定螢幕提醒需另外處理。

    6. 不同瀏覽器／裝置的 localStorage 不會自動同步。
