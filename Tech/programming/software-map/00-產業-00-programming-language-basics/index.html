    程式語言基本概況¶

    程式語言是人類用來描述指令、邏輯與資料處理規則，讓電腦執行工作的工具。

    不同程式語言各有設計理念、應用領域與生態系，沒有一種語言適合所有情境。

    ① 依照應用領域分類¶

    💻 程式語言
│
├── Web 開發
│   ├── 前端 → JavaScript / TypeScript
│   └── 後端 → Java、C#、Python、Ruby、Go、PHP
│
├── 系統與底層開發
│   └── C、C++、Rust
│       → 作業系統、驅動程式、效能要求高的軟體
│
├── 手機 App 開發
│   ├── Android → Kotlin、Java
│   └── iOS → Swift
│
├── 遊戲開發
│   ├── Unity → C#
│   ├── Unreal Engine → C++
│   └── Godot → GDScript、C#
│
├── AI、資料科學、自動化
│   ├── Python → AI、資料分析、自動化
│   └── R → 統計分析、資料科學
│
└── 資料庫查詢
    └── SQL
        → 查詢、修改與管理關聯式資料庫

    同一種語言可以應用在多個領域，例如 Python 能開發 Web、AI、自動化工具。

    ② 依照語言層級分類¶

    分類 說明 例子
    機器語言 CPU 能直接執行的機器指令 二進位機器碼
    組合語言 使用助記符表示機器指令，與硬體架構密切相關 Assembly
    高階語言 抽象化硬體細節，讓人類更容易開發 Python、Java、C、Ruby

    重點： 高階不代表效能差，低階也不代表技術比較厲害；主要差別是抽象化程度。

    ③ 依照型別系統分類¶

    分類 說明 例子
    靜態型別 通常在執行前檢查型別 C、C++、C#、Java、Go、TypeScript
    動態型別 主要在執行時檢查型別 Python、Ruby、JavaScript

    例如：

    # Python：動態型別
value = 10
value = "Hello"

    // TypeScript：靜態型別
let value: number = 10;
// value = "Hello"; // 型別檢查錯誤

    重點： 靜態型別與動態型別不是優劣排名，而是不同的設計取捨。

    ④ 依照執行方式分類¶

    編譯執行
原始碼 → 編譯器 → 機器碼 → CPU 執行
例：C、C++（常見方式）

虛擬機與中介碼
原始碼 → 編譯成中介碼 → 虛擬機執行
例：Java / JVM、C# / .NET

直譯與執行環境
原始碼 → 執行環境處理並執行
例：Python、Ruby、JavaScript

    以上是簡化的常見執行模型。現代語言執行環境可能同時使用編譯、直譯、JIT 等技術，因此不能完全以語言名稱二分。

    ⑤ 依照程式設計典範分類¶

    典範 核心概念 常見語言
    程序式 依照步驟與函式組織程式 C、Python
    物件導向（OOP） 以物件組織資料與行為 Java、C#、Ruby
    函數式 以函式組合與資料轉換表達邏輯 Haskell、Elixir
    宣告式 描述想得到的結果，而非每個執行步驟 SQL

    重點： 多數現代程式語言支援多種典範，例如 Python、JavaScript、C# 都能混合不同寫法。

    重點整理¶

    • 應用領域：這個語言通常拿來做什麼？
    • 語言層級：與硬體之間有多少抽象化？
    • 型別系統：何時檢查資料型別？
    • 執行方式：程式碼如何轉換並執行？
    • 程式設計典範：如何組織程式邏輯？

    結論： 程式語言可以從多個角度分類，沒有唯一的分類樹。選擇語言時，優先考慮想開發的產品、職缺需求與技術生態系。
