    Linux Applications（應用程式）¶

    開發工具（Development Tools）¶

    類別 軟體 特色／用途
    程式編輯器 VS Code 編輯程式碼與管理開發專案。
    版本控制 Git 管理程式碼版本與變更紀錄。

    終端機與命令列（Terminal & CLI）¶

    類別 軟體 特色／用途
    Shell Zsh 功能豐富，可搭配 Oh My Zsh、Powerlevel10k。
    Shell Fish 提供友善的互動式命令列體驗。
    終端機 Kitty 功能豐富的終端機模擬器。
    終端機 Alacritty 著重效能與精簡設計的終端機模擬器。
    終端機分割與工作階段管理 tmux 在終端機中管理多個窗格與工作階段。
    模糊搜尋 fzf 快速搜尋檔案、命令歷史與其他清單。

    系統監控（System Monitoring）¶

    類別 軟體 特色／用途
    硬體與系統監控 btop 查看 CPU、記憶體、磁碟與程序等資訊。
    系統資訊 fastfetch 在終端機顯示系統與硬體資訊。

    檔案與文件處理（Files & Documents）¶

    類別 軟體 特色／用途
    辦公軟體 ONLYOFFICE 編輯文件、試算表與簡報。

    網路與瀏覽器（Web & Browsers）¶

    類別 軟體 特色／用途
    瀏覽器 Helium 網頁瀏覽工具，之後可補充安裝方式與特色。
