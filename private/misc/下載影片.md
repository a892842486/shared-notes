# 下載網路影片（YouTube 也適用）

2026-11-05 Created

---

## 方法一：網站直接提供 MP4

適合可以直接取得 `.mp4` 網址的網站。

1. 播放影片，切換最高畫質。
2. 按 `F12` → 左上角 **Select an element** → 點選影片。
3. 找到右邊的 `.mp4` 網址，複製後貼到新分頁。
4. 如果成功開啟影片，點播放器右下角的 **Download** 下載。

> 有些網站使用串流播放，找不到 MP4 就改用方法二。

## 方法二：yt-dlp 下載（推薦）

適合 YouTube，以及其他 yt-dlp 支援的影片網站。

**優先使用影片的原始網頁網址，不需要自行尋找 MP4 或 m3u8。** yt-dlp 會自動解析網站，尋找可用的影片格式並下載。

### 1. 安裝工具（Windows）

開啟 PowerShell，依序安裝 **Python、yt-dlp、FFmpeg**：

```powershell
winget install Python.Python.3.13
winget install yt-dlp.yt-dlp
winget install Gyan.FFmpeg
```

安裝完成後，**重新開啟 PowerShell**，安裝 Python 版 yt-dlp 與相關依賴：

```powershell
py -m pip install -U "yt-dlp[default,curl-cffi]"
```

確認工具版本：

```powershell
py --version
yt-dlp --version
ffmpeg -version
py -c "import yt_dlp; print(yt_dlp.version.__version__)"
py -c "import curl_cffi; print(curl_cffi.__version__)"
```

**全部正常顯示版本資訊，就代表安裝成功。**

> 注意：Chrome Extension 透過 Python 呼叫 yt-dlp，因此必須安裝 Python 版 yt-dlp 與 `curl_cffi`，不能只安裝獨立版 `yt-dlp.exe`。

### 2. 基本指令（平常用這個）

自動下載最佳可用畫質，使用影片標題命名，並指定儲存位置。

```powershell
yt-dlp -P "影片儲存位置" -o "%(title)s [%(resolution)s].%(ext)s" "原始影片網址"
```
例如
```powershell
yt-dlp -P "F:\download" -o "%(title)s [%(resolution)s].%(ext)s" "原始影片網址"
```


| 參數 | 功能 |
|---|---|
| `yt-dlp` | 執行下載工具 |
| `-P` | 指定下載資料夾 |
| `"影片儲存位置"` | 例如 `F:\download` |
| `-o` | 自訂檔名格式 |
| `%(title)s` | 影片標題 |
| `%(resolution)s` | 影片解析度，例如 3840x2160 |
| `%(ext)s` | 副檔名，例如 mp4 |
| `"原始影片網址"` | 貼上影片的網頁網址 |

下載後的檔名範例：

`影片標題 [3840x2160].mp4`

### 3. 進階指令（需要控制畫質時）

優先選擇不超過 4K 的最佳畫質，並在合併影音時使用 MP4 容器。

```powershell
yt-dlp -f "bv*+ba/b" -S "res:2160" --merge-output-format mp4 -P "影片儲存位置" -o "%(title)s.%(ext)s" "原始影片網址"
```

| 參數 | 功能 |
|---|---|
| `-f` | 指定影片、音訊的選擇規則 |
| `"bv*+ba/b"` | 優先選擇最佳影像＋音訊組合，無法組合時退回單一影音格式 |
| `-S` | 指定畫質排序偏好 |
| `"res:2160"` | 優先選擇不超過 4K 的解析度 |
| `--merge-output-format mp4` | 合併影音時使用 MP4 容器，不重新編碼 |

> 注意：MP4 是容器格式，不代表影片一定是 H.264 編碼。

## 方法三：原始網址無法下載時（F12 找 m3u8）

適合 yt-dlp 無法直接解析網頁，但瀏覽器可以正常播放的情況。

1. 按 `F12` → **Network** → Filter 輸入 `m3u8`。
2. 重新整理網頁，播放影片並切換最高畫質。
3. 找到想要的畫質，例如 `2160p.m3u8`。
4. 點選該項目 → **Headers** → 複製 **Request URL**。
5. 開啟終端機，輸入：

```powershell
yt-dlp -P "影片儲存位置" -o "自訂影片名稱.%(ext)s" "剛剛複製的m3u8網址"
```

> 注意：m3u8 是串流播放清單，不是完整 MP4。yt-dlp 會下載影片片段並合併。

> 使用 m3u8 網址通常抓不到原始影片標題，因此建議自己命名。

## 其他常用指令

**查看有哪些畫質：**

```powershell
yt-dlp -F "原始影片網址"
```

**只查看影片標題，不下載：**

```powershell
yt-dlp --skip-download --print title "原始影片網址"
```

**查看 yt-dlp 版本：**

```powershell
yt-dlp --version
```

**更新 yt-dlp：**

```powershell
yt-dlp -U
```

如果使用 winget 安裝且無法透過 `-U` 更新，可以改用：

```powershell
winget upgrade yt-dlp.yt-dlp
```

如果需要更新 Python 版 yt-dlp 與相關依賴：

```powershell
py -m pip install -U "yt-dlp[default,curl-cffi]"
```

**顯示詳細下載紀錄（除錯用）：**

```powershell
yt-dlp -v "原始影片網址"
```

`-v` 會顯示詳細執行紀錄，包括 yt-dlp 版本、解析過程、使用的下載格式及錯誤訊息，方便排查下載失敗的原因。

> 實測 Youtube 可直接使用原始影片網址下載，不需要手動尋找 m3u8。若下載失敗，可先更新 yt-dlp，再使用 `-v` 查看錯誤原因。

## 常用檔名變數

| 變數 | 功能 |
|---|---|
| `%(title)s` | 影片標題 |
| `%(ext)s` | 副檔名 |
| `%(id)s` | 影片 ID |
| `%(uploader)s` | 上傳者名稱 |
| `%(upload_date)s` | 上傳日期 |
| `%(resolution)s` | 影片解析度 |

## 注意事項

- 優先使用**方法二**，最方便。
- `-P` 控制下載位置，`-o` 控制檔名。
- yt-dlp 預設會選擇最佳可用格式，通常不需要額外指定畫質。
- 來源只有 1080p，就無法直接下載成真正的 4K。
- `.m3u8` 網址可能有期限，過期就要重新取得。
- 不是所有網站都支援 yt-dlp，也不是所有影片都允許下載。
- 僅下載有權保存的影片，尊重版權與出演者的公開意願。
