    C++¶

    基本介紹¶

    C++（C Plus Plus）：Bjarne Stroustrup 於 1980 年代在貝爾實驗室開發，以 C 語言為基礎，加入更多管理複雜程式的功能。

    • C++（程式語言）：保留 C 語言對記憶體與系統資源的控制能力，並加入物件導向（OOP）、泛型等功能。
    • 主要特色：執行效率高、控制力強，常用於遊戲引擎與需要高效能的軟體。

    名稱由來：
    - 最初稱為 C with Classes。
    - ++ 是程式語言中的遞增運算子，象徵 C 的進一步發展。

    應用範例：
    - 遊戲開發：Unreal Engine、3D 遊戲。
    - 桌面軟體：影像編輯、3D 建模工具。
    - 系統軟體：瀏覽器引擎、資料庫。
    - 高效能運算：模擬運算、即時資料處理。

    核心特色¶

    1. 高效能、底層控制¶

    • 通常編譯成機器碼後直接執行。
    • 可控制記憶體與系統資源。
    • 適合大量運算、低延遲、高效能軟體。

    2. 物件導向與泛型¶

    • OOP：Class、繼承、多型。
    • Generic Programming：Template（模板）。
    • 支援多種程式設計風格，方便組織大型專案。

    3. 記憶體管理¶

    • 沒有內建自動垃圾回收（Garbage Collection）。
    • 常使用 RAII、智慧指標管理資源。
    • 也能手動配置與釋放記憶體。

    4. 零開銷原則（Zero-overhead Principle）¶

    • 不使用的語言功能，不應產生額外成本。
    • 使用的抽象功能，應盡可能接近手寫底層程式的效能。

    注意：
    - 語言功能多，學習難度較高。
    - 記憶體操作錯誤可能造成崩潰、安全漏洞。

    常見開發工具¶

    工具 用途
    GCC / G++ C / C++ 編譯器工具鏈
    Clang C / C++ 編譯器
    MSVC Microsoft C / C++ 編譯器

    CMake 跨平台建置系統產生工具
    Visual Studio Windows 常見的 C++ IDE
    VS Code 程式碼編輯器，搭配 C++ 擴充功能

    重點整理¶

    • C++：編譯型、多範式、高效能程式語言。
    • 主要優勢：執行效能、底層控制、物件導向、泛型。
    • 常見領域：遊戲引擎、系統軟體、專業軟體、機器人、金融。
    • 學習重點：指標、記憶體管理、OOP、Template、RAII。
    • 與 C 的差異：C++ 提供更豐富的抽象與程式設計工具，但語言複雜度也更高。
