# 遠端連線工具比較

| 工具 | 適合用途 | 優點 | 延遲（參考） |
|---|---|---|---|
| Sunshine + Moonlight + Tailscale | 遊戲、開發、影片剪輯、完整桌面操作 | 低延遲、用途廣 | 約 20–40ms |
| Chrome Remote Desktop | 臨時遠端、拿檔案、協助家人 | 安裝簡單、容易使用 | 約 80–150ms |
| RDP（Windows 遠端桌面） | 文書、VS Code、Terminal、IT 維護 | 文字清晰、頻寬需求低 | 約 10–30ms（文書操作體感） |

## 工具原理

- **Sunshine + Moonlight：** 串流傳送桌面畫面，並回傳鍵盤、滑鼠與手把操作，適合遊戲及一般桌面操作。
- **Chrome Remote Desktop：** 透過網路傳送遠端桌面畫面，優先考量易用性與相容性。
- **RDP：** 傳送桌面更新與操作資料，適合文書和開發工作，不以遊戲串流為主要用途。

> 延遲為參考值，實際表現取決於網路、設備與設定。
