# Sunshine, Moonlight 安裝方式

## 用途

透過手機、平板或其他設備，遠端操作家中電腦。

- **遊戲：** 外出搭配藍牙手把遊玩。
- **日常操作：** 上網、寫程式、編輯試算表。
- **大螢幕：** 在電視上遊玩或操作電腦。

## 軟體分工

| 軟體 | 用途 | 安裝位置 |
|---|---|---|
| Sunshine（太陽） | 提供遠端畫面與操作服務 | 家中主力電腦 |
| Moonlight（月亮） | 接收畫面、傳回鍵鼠與手把操作 | 手機、平板或其他設備 |
| Tailscale（Tail） | 建立設備間的安全連線，方便從外網連回家 | 家中電腦與外出設備 |

## 安裝與設定

- **Sunshine：** 安裝在家中主力電腦並啟動。
- **Moonlight：** 安裝在要用來遠端操作的設備。
- **Tailscale：** 兩端都安裝，並登入同一個帳號。
- **手把無反應：** 可嘗試以管理員身分啟動 Sunshine。
- **切換中文：** 在 Sunshine 設定頁面選擇語言，再按 F5 重新整理。

## 連線方式

### 家中區域網路

1. 家中電腦與外出設備連上同一個路由器的網路，有線或 Wi-Fi 均可。
2. 開啟 Sunshine。
3. 在 Windows 執行 `ipconfig`，找到 IPv4 位址。
4. 開啟 Moonlight，輸入電腦 IP 並完成配對。

### 外部網路

1. 家中電腦與外出設備都啟動 Tailscale。
2. 確認兩台設備已連線。
3. 在 Moonlight 新增家中電腦，使用 Tailscale 提供的 IP 位址連線。

> Tailscale 使用自己的帳號系統，不必綁定 Google 帳號。

## Moonlight 畫質與流量設定

| 使用情境 | FPS | 解析度 | 碼率 |
|---|---:|---|---:|
| 外出 4G／5G | 60 | 1080p | 8 Mbps |
| 網路不佳／節省流量 | 60 | 720p | 5 Mbps |
| 遠端桌面、文書、VS Code | 60 | 1080p | 2–5 Mbps |
| 家中 Wi-Fi／有線網路 | 60 | 1080p | 15–20 Mbps |
| iPad／電視／大螢幕 | 60 | 1080p | 15–20 Mbps |

以上為建議起始值，可依網路品質、畫質與流量需求調整。

## 日常使用

- **家中電腦：** Sunshine 與 Tailscale 保持啟動，需要遠端時才能立即連線。
- **外出設備：** 有需要時再開啟 Moonlight。
- **資源消耗：** 未串流時通常不會有明顯額外負擔，實際情況依設定而異。

## 其他設定

- **Mac 鍵位調整：** 若需要交換 Ctrl 與 Command，可使用 [Karabiner-Elements](https://karabiner-elements.pqrs.org/)。
- **電視遊玩：** 可在電視或連接電視的設備安裝 Moonlight。

## 實測紀錄

| 連線方式 | 實測延遲 |
|---|---:|
| 有線網路 → Wi-Fi | 4 ms |
| 有線網路 → 4G | 30 ms |
