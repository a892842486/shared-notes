# 認識 NAS

## 基本介紹

### 運作概念

NAS：透過網路讓其他設備存取檔案，是私人雲端。

Google 雲端：資料存在 Google 的伺服器(硬碟)。
NAS：資料存在自己家裡的硬碟。

### 注意事項

1. 不關機：方便隨時存取檔案。
2. 功耗：專用 NAS 約 5～25W（一年電費約 NT$170～850）；Windows 舊電腦約 20～60W (NT$680~2040)。
3. 網路：家中區域網路通常沒問題；若要從外網存取，可使用 Tailscale 等 VPN 工具。
4. 硬碟故障：重要資料要額外備份（考慮成本，不必整顆備份）。
5. 關機無法存取：電腦關機後，其他設備就無法存取檔案。

## NAS 硬體選擇與差別

### 硬體選擇

1. 專用 NAS（專門用來存取檔案）

    - 套裝機：購買 Synology、QNAP 等品牌的 NAS，通常已經裝好自己的作業系統。
    - 自組電腦：自己挑選零件組裝，再安裝 TrueNAS、Unraid、OpenMediaVault 等 NAS 系統。
    - 舊電腦改裝：把閒置電腦安裝 NAS 系統，專門用來存放與共享檔案。

2. 現有電腦兼作 NAS

    - Windows／Mac：使用內建的 SMB 檔案共享功能，電腦開機並保持連線時，其他設備就能存取檔案，不必另外安裝 NAS 系統。

### 差別

| 需求 | 可考慮的方案 |
|---|---|
| 只想共享現有電腦的檔案 | Windows／macOS 內建 SMB |
| 想把舊電腦改成 NAS | OpenMediaVault |
| 想研究 ZFS、快照與資料管理 | TrueNAS |
| 想混用不同容量的硬碟，也想跑 Docker、虛擬機器 | Unraid |

> NAS 系統多數以 Linux 為基礎；TrueNAS、Unraid、OpenMediaVault 都是常見選擇。


## 實際操作

### Windows 分享方式

1. 在 Windows 桌機建立一個資料夾，例如 `D:\shared`。
2. 右鍵點擊資料夾 →「內容」→「共用」→「進階共用勾選」→「共用此資料夾」→「確定」。
3. 「共用...」→ 選「everyone」→「新增」→「共用」。
4. 右鍵內容共用的網路路徑，就是這個資料夾的路徑。
5. 搜尋「管理進階共用設定」。確認 Windows 已開啟「網路探索」與「檔案及印表機共用」。
6. 在其他電腦透過網路連線：
    - Windows：在檔案總管輸入 `\\電腦名稱\共享名稱`。
    - Mac：在 Finder 按 `Command + K`，輸入 `smb://電腦名稱/共享名稱`，選擇訪客存取。

例如：
- Windows：`\\BAMU-PC\shared`
- Mac：`smb://BAMU-PC/shared`
- Iphone：檔案→三個點→連接伺服器→路徑→訪客。 `smb://IP位置` (例如 `smb://192.168.1.108`)

> 注意：Windows 使用 `\\` 開頭，Mac 使用 `smb://` 開頭。
> 注意：分享檔案的電腦關機或睡眠時，其他設備通常就無法存取；重新開機並恢復網路後，即可繼續使用。

### Mac Mini 分享方式

1. 在 Mac mini 建立一個資料夾，例如 `shared`。
2. 共享資料夾：對資料夾「右鍵」→「取得資訊」→ 勾選「共享的檔案夾」→「共享」。
3. Mac共享設定：開啟「系統設定」→「一般」→ 打勾「檔案共享」→ 打勾「完全取用磁碟」。
4. 確認共享電腦：點檔案共享旁的 i → 「選項」→ 打勾 Bamu → 輸入 Mac 解鎖密碼 → 「完成」。
5. 在其他電腦透過網路連線：
    - Windows：在檔案總管輸入 `\\Mac的IP位址\共享資料夾名稱`。
    - Mac：在 Finder 按 `Command + K`，輸入 `smb://Mac的IP位址/共享資料夾名稱`。
6. 輸入 Mac 的使用者帳號與密碼，即可存取共享資料夾。

> ip 位置在 Mac → wifi → 詳細設定 → 有線網路 → ip 位置

> 注意：若要把 Mac mini 當作長期運作的 NAS，記得設定螢幕關閉後不要讓整台電腦自動睡眠，否則其他設備可能無法存取檔案。
