# 軟體產業總覽

> 程式語言不等於職業。同一種語言可以應用於不同領域，選擇就職方向時，應先理解工作內容，再研究對應技術。

## 軟體工程師就職地圖

```text
💻 軟體產業
│
├── 🌐 Web 開發
│   ├── Frontend → HTML、CSS、JavaScript / TypeScript
│   ├── Backend → Java、C#、Python、Ruby、PHP、Go
│   └── Full Stack → 前端 + 後端
│
├── 🎮 遊戲開發
│   ├── 客戶端 → Unity / C#、Unreal / C++
│   ├── 伺服器 → C++、C#、Go、Java
│   └── 引擎 / 圖形 → C++、Shader
│
├── 📱 手機 App 開發
│   ├── iOS → Swift
│   ├── Android → Kotlin、Java
│   └── 跨平台 → Flutter / Dart、React Native
│
├── 🖥️ 桌面 App 開發
│   ├── Windows → C# / .NET、C++
│   ├── macOS → Swift、Objective-C
│   └── 跨平台 → Electron、Qt、Flutter
│
├── 🤖 AI / Data
│   ├── AI / Machine Learning → Python
│   └── 資料分析 / 資料科學 → Python、R、SQL
│
├── ☁️ Cloud / DevOps
│   ├── Cloud → AWS、Azure、GCP
│   ├── DevOps → CI/CD、自動化部署
│   └── Infrastructure → Linux、Docker、Kubernetes
│
├── 🏢 企業軟體
│   ├── Java / Spring Boot
│   ├── C# / .NET
│   └── ERP、CRM、企業內部管理系統
│
├── 🧪 軟體測試 / QA
│   ├── Manual Testing → 人工測試
│   └── Automation Testing → 自動化測試
│
└── 🔧 Embedded / IoT
    ├── C、C++
    ├── MCU（微控制器）
    └── Embedded Linux、IoT
```

> 以上為常見領域與代表性技術，並非互斥分類。例如企業軟體也可能是 Web 系統，DevOps 也會服務遊戲與 App 團隊。

## 技術角色與關係

| 技術 | 主要用途 |
|---|---|
| 程式語言 | 用什麼語言撰寫程式 |
| Framework（框架） | 提供特定類型軟體的開發架構與工具 |
| Engine（引擎） | 提供遊戲等應用的核心運作與開發功能 |
| HTML / CSS | 定義網頁結構與外觀 |
| Database（資料庫） | 儲存、查詢與管理資料 |
| Cloud（雲端） | 提供運算、儲存與網路等基礎設施服務 |
| DevOps | 透過開發與維運協作、自動化改善軟體交付與運作 |

## 重點整理

- **程式語言 ≠ 職業**：Python 可以做 Web、AI、資料分析、自動化。
- **同一職業 ≠ 單一語言**：後端工程師可能使用 Java、C#、Go、Ruby 等。
- **Framework ≠ 程式語言**：Ruby 是語言，Ruby on Rails 是框架。
- **領域可能重疊**：企業系統可能是 Web，遊戲公司也需要後端、QA、DevOps。

**結論：** 先選擇想從事的軟體領域與職務，再研究相關程式語言、框架及工具。
