# Raspberry Pi 樹莓派入門

樹莓派（Raspberry Pi）是一種**體積小、低功耗的單板電腦**，可以安裝作業系統、執行程式，也能連接電子零件。

常見系統是官方的 Raspberry Pi OS（基於 Debian Linux），也支援 Ubuntu 等系統。

## 型號與價格

| 型號 | RAM | CPU | 參考價格（NT$） |
|---|---:|---|---:|
| Raspberry Pi Zero 2 W | 512MB | 4 核心，1GHz | 800–1,000 |

> 價格為參考值，非即時報價。主板通常不含電源、記憶卡、外殼與散熱配件。

### RAM 怎麼選？

- **2GB：** Linux 入門、簡單網路服務。
- **4GB：** 個人伺服器、一般開發實驗。
- **8GB：** 同時執行多個服務或較吃記憶體的應用。

RAM 越大，可供程式使用的記憶體越多，但不代表所有用途都需要更大容量。

## 實際用途

- **遠端喚醒電腦：** 樹莓派保持在線，人在外面透過 VPN／Tailscale 連回家，再使用 Wake-on-LAN 喚醒家中的桌機。
- **家用伺服器：** 架設個人網站、檔案服務，或接上 USB SSD 提供家中檔案存取。
- **常駐服務：** 24 小時執行 Pi-hole，過濾部分廣告與追蹤網域，或管理智慧家庭設備。
- **硬體控制：** 用 Python 控制 LED、讀取溫濕度，或透過驅動電路控制馬達。
- **專用設備：** 製作電子看板，開機便自動顯示天氣、行事曆或其他資訊。

> 遠端喚醒需要家中電腦、網路設備支援相關功能，並正確設定 WoL 與安全的遠端連線方式。

## ESP32 是什麼？

ESP32 是一種**低成本、低功耗的微控制器**，許多型號內建 Wi-Fi、藍牙，適合控制電子設備與製作自動化工具。

例如：
- **車庫門控制：** 用手機控制既有車庫門，並回報門是否關好。
- **自動澆水：** 偵測土壤濕度，太乾時自動啟動水泵。
- **智慧家庭：** 監測溫濕度，將資料傳送到家庭自動化系統。

## ESP32 vs. Raspberry Pi

| 比較 | ESP32 | Raspberry Pi Zero 2 W |
|---|---|---|
| 本質 | 微控制器 | 單板電腦 |
| 作業系統 | 通常直接執行韌體 | 可執行 Linux |
| 主要用途 | 感測器、設備控制 | 網路服務、較複雜的程式 |
| 參考價格 | 約 NT$100–400 | 約 NT$800–1,000 |

**簡單理解：ESP32 像設備的控制大腦，樹莓派則像一台小電腦。**

如果想製作自動澆水、溫濕度監測或車庫門控制器，ESP32 通常更便宜、省電；如果需要 Linux、資料庫或較複雜的網路服務，則可考慮樹莓派。

> 價格依型號與通路而異。控制車庫門或馬達時，必須使用適當的驅動電路，並保留原有安全機制。

## 結論

樹莓派的特色是**低功耗、體積小、可長時間運作，以及方便連接電子零件**。

目前已有 Mac mini 和 Windows 桌機，學習 Linux、架設網站不必額外購買。

若想讓樹莓派全天在線，從外面遠端喚醒家中電腦、提供家庭網路服務，或製作開機就自動顯示資訊的電子看板，再考慮購買；若主要是控制燈光、監測溫濕度或自動澆水，ESP32 可能更划算。
