# Windows 系統虛擬螢幕

來源 https://github.com/VirtualDrivers/Virtual-Display-Driver


目的
手機 moonlight 電腦，讓手機本身變成雙螢幕。



## 設定虛擬螢幕

1. 終端機輸入 winget install --id=VirtualDrivers.Virtual-Display-Driver -e
2. 重開 終端機，輸入 & "VDD Control" 就打開程式了
3. install 後，win + I > 系統，就有顯示虛擬雙螢幕了
4. 點螢幕 2 設定 1920x1080、進階顯示設定 60Hz
5. win + p 可以確認延伸螢幕狀況

## 設定 moonlight 顯示副螢幕 (手機)，而不是主螢幕

1. 打開 Sunshine，輸入帳號密碼登入
2. 點 疑難排解，找到下面的 log，ctrl + F 搜尋 display_name，有個五號螢幕，就是虛擬副螢幕
看到他前一行長這樣  "device_id": "{d54a4360-26df-5f1a-b161-298c03c03b66}"
但!! 複製 {d54a4360-26df-5f1a-b161-298c03c03b66} 就好。(這是螢幕的ID)

3. 點組態、Audio/Video、把螢幕ID貼在 顯示ID、儲存、套用

4. 重新啟動 Sunshine / Moonlight 即可

## 平常沒使用 Moonlight 時

1. win + I，選 "只在螢幕1顯示"

2. 等有雙螢幕需求的時候再 "延伸這些顯示器"
