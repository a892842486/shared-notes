# 遊戲開發職缺地圖

> ⭐ 台灣相關職缺數量粗估，非實際統計。
> 入門建議：Unity / Unreal Engine 先選一套深入學習。

```text
🎮 遊戲開發
│
├── 遊戲引擎
│   │
│   ├── Unity ⭐⭐⭐⭐
│   │   └── C#
│   │       → 手遊、獨立遊戲、中小型遊戲、跨平台
│   │
│   ├── Unreal Engine ⭐⭐⭐
│   │   └── C++ / Blueprint（視覺化腳本）
│   │       → 高品質 3D、3A、大型遊戲、主機遊戲
│   │
│   ├── Godot
│   │   └── GDScript / C#
│   │       → 2D、獨立遊戲、個人開發
│   │       → 跨平台、職缺相對少
│   │
│   └── RPG Maker
│       → RPG 製作、低程式門檻
│       → 可透過腳本擴充功能
│
├── 程式語言
│   ├── C# → Unity、Godot
│   └── C++ → Unreal、自製遊戲引擎
│
├── 遊戲運行平台
│   ├── 🖥️ 電腦
│   │   ├── Windows
│   │   └── macOS
│   │
│   ├── 📱 手機
│   │   ├── Android
│   │   └── iOS
│   │
│   └── 🎮 家用主機
│       ├── Nintendo Switch / Switch 2
│       ├── PlayStation 5
│       └── Xbox Series X|S
│
└── 遊戲發行平台
    ├── Steam
    ├── Epic Games Store
    ├── App Store
    ├── Google Play
    └── 主機平台數位商店
```

## 重點整理

- **Unity + C#**：手機遊戲、獨立遊戲、跨平台開發。
- **Unreal + C++ / Blueprint**：大型 3D、主機遊戲、高畫質專案。
- **Godot**：免費開源，適合個人與獨立遊戲開發。
- **RPG Maker**：適合快速製作 RPG，不是主流遊戲工程師求職技術。

**結論：** 入門先選 Unity 或 Unreal Engine 一套深入學習即可，不代表業界只能使用其中一套。
