## 市場觀察

- Java / Spring Boot：大型企業需求廣泛，職缺相對多。
- C# / ASP.NET Core：企業內部系統、商業應用常見。
- JavaScript / TypeScript：前端主流，也能開發後端。
- Python：跨 Web、AI、資料處理等領域；Python 整體職缺不等於 Django / FastAPI 職缺。
- PHP / Laravel：網站、電商及既有系統維護。
- Go：雲端服務、微服務、基礎設施相關後端。
- Ruby on Rails：開發效率高，台灣職缺市場相對小。

結論：Rails 適合快速開發完整產品；Java / C# 在台灣企業後端市場的選擇通常較廣。

## 技術層級補充

```text
程式語言 → Runtime（執行環境）→ Framework（框架）→ Web Backend
```

### 基本概念

- **程式語言**：用來撰寫程式，例如 JavaScript、Python、Ruby。
- **Runtime**：提供程式執行所需的環境。
- **Framework**：提供現成的開發架構、工具與常用功能，減少重複開發。
- **Web Backend**：處理請求、商業邏輯、資料庫操作等伺服器端功能。

### 常見組合

```text
JavaScript → Node.js → Express / NestJS → Web Backend

Python → Python 執行環境 → Django / FastAPI / Flask → Web Backend

Ruby → Ruby 執行環境 → Ruby on Rails → Web Backend
```

### 重點

- Node.js：JavaScript 的伺服器端執行環境之一，不是框架。
- Express / NestJS：運行於 Node.js 環境的後端框架。
- Django / FastAPI / Flask：Python Web 框架。
- Ruby on Rails：Ruby Web 框架。
- Runtime 與 Framework 是不同概念，並非所有技術架構都必須依照固定層級組合。
