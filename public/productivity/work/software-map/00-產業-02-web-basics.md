# Web 開發基本概況

## 前端（Frontend）

> 讓使用者能舒服、直覺、有效率地使用網站。

主要工作：

1. **視覺與排版**：網站美化、資訊層次、閱讀舒適度。
2. **RWD 響應式設計**：依照電腦、平板、手機的螢幕尺寸調整版面。
3. **使用者互動**：搜尋欄、返回上一頁、深色模式、選單、表單操作。
4. **資料呈現**：將後端提供的資料顯示成使用者看得懂的畫面。
5. **前端效能**：減少不必要的資源載入、改善畫面顯示與操作速度。

常見技術：HTML、CSS、JavaScript / TypeScript、React、Vue。

## 後端（Backend）

> 負責網站背後的資料處理、商業邏輯與系統運作。

主要工作：

1. **資料處理**：新增、讀取、修改、刪除資料（CRUD）。
2. **商業邏輯**：訂單計算、庫存檢查、訂單狀態轉換。
3. **身分驗證與權限**：登入、註冊、管理員權限。
4. **資料庫操作**：儲存、查詢與維護資料。
5. **API 與系統整合**：提供資料給前端，串接外部服務。
6. **安全與效能**：資料驗證、存取控制、查詢效能。

常見技術：Ruby on Rails、Spring Boot、ASP.NET Core、Django、Laravel、Node.js 生態系框架等。

## 全端（Full Stack）

> 同時具備前端與後端開發能力，能參與網站從畫面到資料處理的開發。

- 前端：畫面、互動、RWD。
- 後端：資料庫、商業邏輯、API。
- 不代表必須精通所有程式語言與框架。

## 網站如何運作？

```text
使用者（瀏覽器）
    ↓ 操作網站、送出請求
前端（Frontend）
    ↓ 發送 HTTP 請求
後端（Backend）
    ↓ 查詢或修改資料
資料庫（Database）
    ↑ 回傳資料
後端（Backend）
    ↑ 回傳 HTML 或 JSON 等回應
前端（Frontend）
    ↓ 顯示結果
使用者看到更新後的畫面
```

以上是常見的前後端互動流程，實際架構可能不同。

## 重點整理

- **Frontend**：使用者看得到、操作得到的網站介面。
- **Backend**：處理資料、商業邏輯與伺服器端功能。
- **Database**：負責資料儲存與查詢。
- **Full Stack**：工作範圍涵蓋前端與後端。
- **網站效能**：前端、後端、資料庫都會影響速度。
