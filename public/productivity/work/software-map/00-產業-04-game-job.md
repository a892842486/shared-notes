## 重點整理

- **遊戲客戶端**：主要開發玩家直接操作與看見的遊戲內容。
- **遊戲伺服器**：負責多人連線、即時同步、遊戲狀態。
- **遊戲平台後端**：負責帳號、商城、API、資料庫等服務。
- **Unity + C#**：常見於手機、獨立與跨平台遊戲。
- **Unreal + C++ / Blueprint**：常見於大型 3D 與高畫質遊戲。
- **Godot**：免費開源，適合個人與獨立開發。
- **RPG Maker**：適合 RPG 製作，不是主流工程師求職技術。

**結論：** 想做遊戲客戶端，入門可先選 Unity 或 Unreal 深入學習；想做遊戲伺服器或平台後端，則應依職缺要求選擇後端語言與技術，不一定需要遊戲引擎。
