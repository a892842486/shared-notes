# C#（C Sharp）

## 基本介紹

C#（念作 C Sharp）：Microsoft 於 2000 年推出的程式語言，主要搭配 .NET 平台開發網站後端、遊戲與各種應用程式。

- C#（程式語言）：用來撰寫程式，語法支援物件導向，並能在編譯時檢查許多型別錯誤。
- .NET（開發平台）：提供執行 C# 程式所需的環境、函式庫與開發工具。

應用範例：
- Web Backend：使用 ASP.NET Core 開發網站後端、Web API。
- Game Development：使用 Unity 開發遊戲。
- Desktop：使用 WinForms、WPF 開發 Windows 桌面軟體。
- Mobile：使用 .NET MAUI 開發跨平台 App。

## 核心特色

### 1. 物件導向（OOP）
- 支援 Class、繼承、封裝、多型。
- 適合組織大型專案，方便維護與擴充。

### 2. 靜態型別、強型別
- 變數與資料具有明確型別，例如 `int`、`string`。
- 編譯階段可發現許多型別相關錯誤。
- 支援型別推斷（`var`），不一定需要手動標註型別。

### 3. 自動記憶體管理
- .NET 提供 Garbage Collection（垃圾回收）。
- 自動回收不再使用的受管理記憶體。
- 檔案、網路連線等資源仍需要適當釋放。

### 4. .NET 生態系
- 提供 Runtime（執行環境）、函式庫與開發工具。
- 支援 Web、Desktop、Mobile 等應用。
- 可跨 Windows、macOS、Linux 開發與執行部分應用程式。

## 常見開發工具

| 工具 | 用途 |
|---|---|
| .NET | 開發平台、執行環境與函式庫 |
| .NET SDK / CLI | 建立、編譯、測試與執行專案 |
| Visual Studio | Microsoft 的整合開發環境 |
| VS Code | 輕量編輯器，搭配 C# 擴充功能 |
| NuGet | .NET 套件管理系統與套件庫 |

補充：
- C#：程式語言。
- .NET：支援 C# 開發與執行的平台。
- ASP.NET Core：建立在 .NET 上的 Web Framework。

## 重點整理

- C#：靜態型別、強型別、支援物件導向的程式語言。
- .NET：C# 常用的開發與執行平台。
- 主要優勢：開發效率、型別安全、自動記憶體管理。
- 常見領域：企業後端、Unity 遊戲、桌面與行動應用。
- ASP.NET Core：C# / .NET 常見的 Web 開發框架。
- C# 與 C++ 是不同語言，並非單純的版本升級關係。
