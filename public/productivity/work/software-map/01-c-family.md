# C / C++ / C# 比較

## 基本比較

| 項目 | C | C++ | C# |
|---|---|---|---|
| 誕生 | 1972 | 1985 | 2000 |
| 主要定位 | 底層、嵌入式 | 高效能、遊戲、系統 | 企業軟體、Web、遊戲 |
| 程式風格 | 程序式 | 多範式、OOP、泛型 | OOP、多範式 |
| 記憶體管理 | 手動 | RAII、智慧指標、手動 | Garbage Collection |
| 主要特色 | 接近硬體、精簡 | 高效能、控制力強 | 開發效率、.NET 生態系 |
| 常見用途 | 作業系統、韌體、驅動 | 遊戲引擎、系統軟體 | Unity、Web Backend、企業系統 |

## 語言關係

- C：以程序式程式設計為主，強調底層控制。
- C++：由 C 發展而來，加入 OOP、Template 等功能。
- C#：Microsoft 設計的獨立語言，語法受 C / C++ 等語言影響，並非 C++ 的升級版。

## 簡單理解

### C
「我要直接控制硬體與系統。」
- 語言精簡、效能高。
- 常用於作業系統、嵌入式、韌體。

### C++
「我要高效能，也需要更多程式設計工具。」
- 底層控制力強，支援 OOP、泛型。
- 適合大型遊戲、引擎與高效能軟體。
- 語言複雜度較高。

### C#
「我要更容易、安全地開發大型軟體。」
- 靜態型別、自動記憶體管理。
- .NET 生態系完整，開發效率高。
- 常用於企業後端、Unity 遊戲。

## 遊戲開發比較

```text
Unreal Engine
│
├── 引擎底層 → 大量使用 C++
│
└── 遊戲開發 → C++ / Blueprint
    └── 高效能、底層控制
        → 大型 3D、3A 遊戲


Unity
│
├── 引擎底層 → 大量使用 C++
│
└── 遊戲開發 → 主要使用 C#
    └── 開發效率高、自動記憶體管理
        → 手機遊戲、獨立遊戲、跨平台
```

## 重點整理

- C：底層控制、嵌入式、作業系統。
- C++：高效能、遊戲引擎、系統軟體。
- C#：.NET、企業後端、Unity 遊戲。
- Unreal：主要使用 C++ / Blueprint 開發遊戲。
- Unity：主要使用 C# 撰寫遊戲邏輯。
- 三種語言各有定位，並非單純的新舊替代關係。
