# C 語言

## 基本介紹

C（C Language）：1972 年由 Dennis Ritchie 在貝爾實驗室開發，最初主要用於 Unix 作業系統。

- C（程式語言）：能直接操作記憶體與系統資源，常用於開發接近硬體的軟體。
- 主要特色：執行效率高、控制力強，但需要自行管理記憶體。

應用範例：
- 作業系統：Linux 核心、Unix。
- 嵌入式系統：家電、電子設備、微控制器。
- 驅動程式：讓作業系統與硬體溝通。
- 底層軟體：資料庫引擎、程式語言直譯器。

## 核心特色

### 1. 接近硬體
- 可透過指標操作記憶體與底層資源。
- 適合系統軟體、驅動程式、嵌入式開發。

### 2. 高效能
- 通常編譯成機器碼後直接執行。
- 適合資源有限或效能要求高的系統。

### 3. 語言簡潔
- 語法與核心功能相對精簡。
- 影響 C++、Java、C# 等後續程式語言。
- 語言精簡不代表容易學習，記憶體與指標操作需要謹慎。

### 4. 手動管理記憶體
- 沒有內建 Garbage Collection（垃圾回收）。
- 動態配置的記憶體通常需要自行釋放。
- 必須注意記憶體洩漏、越界存取等問題。

## 重點整理

- C：編譯型、程序式、偏底層的通用程式語言。
- 主要優勢：高效能、記憶體控制、硬體與系統資源操作。
- 常見領域：作業系統、嵌入式、韌體、驅動程式、資料庫核心。
- 學習重點：指標、記憶體管理、資料結構、系統程式設計。
