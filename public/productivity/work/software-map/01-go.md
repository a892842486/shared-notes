# Go（Golang）

## 基本介紹

Go（Golang）：Google 於 2009 年公開的程式語言，語法簡潔、執行效率高，常用於網站後端、雲端服務與自動化工具。

- Go（程式語言）：適合開發網路服務，能有效率地同時處理大量連線與工作。
- Goroutine（輕量級並行執行單位）：讓程式更容易同時執行多項工作，例如處理多個使用者請求。

應用範例：
- Web Backend：網站後端、Web API。
- Cloud：雲端服務、伺服器程式。
- DevOps：Docker、Kubernetes 等工具。
- Network Services：網路伺服器、代理伺服器。
- CLI Tools：命令列工具、自動化程式。

## 核心特色

### ⚡ 執行效能高
- Go 通常會編譯成機器碼後執行。
- 通常比 Python、Ruby 等動態語言具有更高的執行效能。

### 🚀 高併發（Concurrency）
- 內建 Goroutine（輕量級並行工作單位）。
- 可有效處理大量同時進行的工作，例如網路請求。
- 併發不等於平行執行，實際效能仍取決於硬體與系統架構。

### 📦 部署簡單
- 可編譯成獨立執行檔。
- 通常不需要在目標機器另外安裝 Go。
- 適合伺服器、容器與雲端部署。

### 🧹 語法簡潔
- 語言設計精簡，降低複雜度。
- 強調可讀性與維護性。
- 內建格式化工具，方便統一程式碼風格。

## 代表性 Go 軟體

- Docker：容器技術平台，核心元件大量使用 Go。
- Kubernetes：容器編排系統，主要使用 Go。
- Terraform：基礎設施即程式碼（IaC）工具，主要使用 Go。

## 重點整理

- Go：編譯型、靜態型別、支援高併發的程式語言。
- 主要優勢：效能、部署便利、語法簡潔、併發處理。
- 常見領域：後端、雲端、DevOps、網路服務。
- 不限於 Web 開發，也常用於基礎設施與系統工具。
