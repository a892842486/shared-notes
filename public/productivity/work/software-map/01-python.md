# Python

## 基本介紹

Python：語法簡潔、容易閱讀的程式語言，常用於 AI、資料分析、網站後端與自動化工具。

pip（套件管理工具）：用來安裝其他開發者製作的功能套件。

應用範例：
- Web Backend：使用 Django、FastAPI 開發網站後端、Web API。
- AI / Machine Learning：使用 PyTorch、TensorFlow 開發 AI 模型。
- Data Science：使用 pandas 分析、整理大量資料。
- Automation：自動整理檔案、批次處理資料、執行重複工作。
- Web Scraping：使用 Beautiful Soup、Scrapy 擷取網站資料。
- DevOps / Cloud：撰寫部署腳本、自動管理雲端資源。

## 核心特色

### 1. 語法簡潔、容易閱讀
- 語法接近自然英文，容易理解。
- 通常能用較少的程式碼完成相同功能。
- 適合初學者，也適合快速開發與原型製作。

### 2. 生態系龐大
- 擁有大量現成的 Library（函式庫）與 Package（套件）。
- 常見功能通常已有成熟工具可使用。
- 不需要每次從零開始，可以直接引入並組合使用。

## 常見開發工具

| 工具 | 用途 |
|---|---|
| Python | 程式語言、執行環境 |
| pip | 安裝、管理 Python 套件 |
| venv | 建立虛擬環境，隔離專案依賴 |
| PyPI | Python 套件線上倉庫 |
| VS Code | 程式碼編輯器，搭配 Python 擴充功能 |
| PyCharm | JetBrains 的 Python 專用 IDE |

補充：
- Python：可從官方網站安裝。
- pip：一般安裝 Python 時會一併提供。
- venv：Python 內建模組。
- PyPI：線上套件倉庫，不需要安裝。

官方網站：https://www.python.org/
