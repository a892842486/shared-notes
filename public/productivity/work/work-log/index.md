# Work Log｜工作紀錄

記錄自學程式設計、專案開發與日常工作進度，追蹤每個階段的實際成果。

## 紀錄原則

1. **每日紀錄**：使用 Discord 記錄工作內容、番茄鐘與完成事項。
2. **每週週報**：每七天彙整一次 Discord 內容，保留主要成果、遇到的問題與解決方式。
3. **每月歸檔**：每個月使用一份 `.md`，避免檔案過度分散。
4. **精簡呈現**：以完成事項為主，省略重複細節與私人資訊。

## 目的

- 追蹤專案開發與學習進度。
- 回顧遇到的問題及解決成果。
- 保留持續學習與實作的紀錄。

> Discord 保留完整日誌，這裡僅公開整理後的工作成果。
